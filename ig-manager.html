Integrasi Meta Graph API & Script Auto-Publisher

Pengaturan token Instagram Graph API dan generator script eksekusi terminal otomatis.

Konfigurasi Kredensial Meta Developer

💡 Panduan Memperoleh Token:
  1. Buka developers.facebook.com > Buat App (Tipe Business).
  2. Tambahkan produk Instagram Graph API.
  3. Dapatkan User Token dengan izin instagram_content_publish.

Script Python Siap Eksekusi

# Script Otomatisasi Upload Instagram Agrotech # Menghubungkan ke Meta Graph API v19.0 import requests IG_USER_ID = "17841405829103841" ACCESS_TOKEN = "EAAG_SAMPLE_TOKEN_AGROTECH_SECURE_KEY" IMAGE_URL = "https://agrotech.id/assets/ig_reels_promo_1.jpg" CAPTION = "Stop bertani pakai cara tebak-tebakan! 🚜⚡ Saatnya ke Pertanian 4.0 bersama Agrotech! #SmartFarming #Agrotech" # Langkah 1: Buat Media Container url_container = f"https://graph.facebook.com/v19.0/{IG_USER_ID}/media" payload_container = { 'image_url': IMAGE_URL, 'caption': CAPTION, 'access_token': ACCESS_TOKEN } res_container = requests.post(url_container, data=payload_container).json() container_id = res_container.get('id') print("Container ID:", container_id) # Langkah 2: Publikasikan Container url_publish = f"https://graph.facebook.com/v19.0/{IG_USER_ID}/media_publish" payload_publish = { 'creation_id': container_id, 'access_token': ACCESS_TOKEN } res_publish = requests.post(url_publish, data=payload_publish).json() print("Hasil Publikasi:", res_publish)
